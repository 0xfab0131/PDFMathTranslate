# Glossary Notes

This folder contains tracked starter glossaries intended for review before use.

The file `category-topos-alggeo-ja.example.csv` is a conservative starting point
for category theory, topos theory, algebraic geometry, and sheaf theory.

Recommended usage:

1. Review the CSV manually before first use.
2. Keep only the terms whose Japanese rendering you want to enforce.
3. Upload the CSV from the GUI glossary input, or set `translation.glossaries`
   in `config/pdf2zh_next.openai.toml` after review.

Do not assume every entry is universally optimal in every paper. Context matters.
